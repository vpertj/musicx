# MusicX UI 重构设计 ——「月光极简」

> 日期:2026-09-01
> 状态:Design(待用户审阅)
> 范围:整体视觉风格(theme)、导航信息架构、播放页布局、歌词/唱盘切换、组件规范

---

## 1. 背景与目标

### 1.1 现状问题(用户/产品诊断)

当前 UI 是功能迭代中"能用就行"地堆出来的,存在以下已被用户察觉的问题:

1. **导航结构混乱**:"播放"被做成顶级 tab——播放页理应从歌曲点进去的上下文页,不该与"发现/我的"平级;桌面侧边栏里"下载音乐/设置"是**跳转式入口**(push 新页面),与 tab 混在一起,层级不统一;播放 UI 两套逻辑重复(顶级"播放"tab 常驻 + 从迷你条展开的全屏播放器)。
2. **配色偏"电竞感"**:强调色为紫(`0xFF8B5CF6`)→粉(`0xFFEC4899`)渐变,播放键/进度条/Logo/徽标到处使用;深色背景 `0xFF0D0A16`(偏紫黑)+ 卡片 `0xFF171226`;页面色系与播放页渐变色系不一致。
3. **布局层级**:侧边栏固定 220 宽,Logo+导航+歌单+设置全堆一列,信息密度偏大;播放页底部塞进度条+时间+控制键+队列入口,视觉重心偏下。

### 1.2 参考产品

以头部音乐 App 的布局配色规律为对照基准:
- **网易云音乐**(2024 改版,删繁就简回归音乐;黑胶播放页;底部导航 5 tab,无独立"播放"tab)
- **QQ 音乐**(品牌绿点缀;卡片流首页;单封面播放页)
- **酷狗 / 酷我**(各自品牌蓝/粉点缀;底部控制键)

### 1.3 设计目标

- 极简克制,聚焦音乐本身:界面退到幕后,把注意力留给封面与歌词。
- 颜色只表达**状态**,不用于**装饰**。
- 与头部产品布局对齐:播放页不占一级 tab,"我的"页为资产中心,品牌色做点缀。

### 1.4 已确认决策

| 决策点 | 结论 |
|---|---|
| 重构范围 | 导航结构 + 配色体系 + 播放页布局 + 主题切换机制,一次到位 |
| 配色方案 | 方案 A「月光极简」:黑白灰骨架 + 品牌红点缀 |
| 明暗模式 | 浅色为主(默认),手动切深色(持久化) |
| 底部/侧边导航 | **三个入口:发现 / 我的 / 设置**;播放页不占 tab |

## 2. 设计原则

1. **留白即高级**:卡片不堆边框,靠间距与灰度层级表达结构。
2. **单色点缀**:黑白灰是骨架,品牌红只出现在"正在播放/当前选中/可操作"处。
3. **层级靠字重与灰度**,不靠彩色。
4. **移除全部渐变**用于 UI 元素(播放键、进度条、Logo、徽标);封面自身的自然色彩保留。
5. **一致性**:所有颜色通过语义 Token 引用,不散落硬编码色值。

---

## 3. 配色体系(语义色 Token)

基于一套语义 Token 组织两套明暗主题。

| Token | 浅色(默认) | 深色(手动) | 用途 |
|---|---|---|---|
| `bg` | `#FAFBFC` | `#121212` | 页面背景 |
| `surface` | `#FFFFFF` | `#1E1E1E` | 卡片/表面 |
| `surfaceHi` | `#F2F3F5` | `#242629` | 悬浮/输入框/次级表面 |
| `text` | `#1A1C1E` | `#F3F4F6` | 主文字 |
| `textMuted` | `#8A8F98` | `#9AA1AB` | 次要文字 |
| `divider` | `#E7E9EC` | `#2C2F33` | 分隔线 |
| `accent` | `#FA3B4D` | `#FF4559` | 品牌红:播放键/进度条/当前高亮 |
| `accentSoft` | `#FFEDEE` | `#3A2225` | 品牌红浅底:选中态背景/徽标 |

> **注意**:`accent` 是唯一彩色点缀。深色背景用近纯黑 `#121212`(不是紫黑),避免残存的紫色调。

## 4. 导航信息架构(三 tab)

### 4.1 导航结构

```
/ 底部或侧边导航(桌面侧边栏 220px,移动端底部栏)— 一致的三入口
[ 发现 ]  [ 我的 ]  [ 设置 ]
```

| 入口 | 承载内容 | 说明 |
|---|---|---|
| **发现** | 搜索条 + 音源切换 + 首页内容卡片流 | App 门面,体现"插件聚合搜索"卖点 |
| **我的** | 资产中心:歌单 / 收藏 / 下载 / 本地 / 历史 | 用户内容统一入口 |
| **设置** | 音源管理 / 插件 / 外观(深浅色)/ 关于 | 低频率管理与偏好 |

### 4.2 关键变更

- **移除"播放"顶级 tab**:播放页改为从迷你条 / 点击歌曲进入的全屏页。
- **下载音乐不再占独立导航入口**,并入"我的"页作为分区。
- **歌单列表不再挤在侧边栏**,在"我的"页内管理。
- **设置成为一级 tab**(用户已确认三 tab),承载外观深浅色切换入口。

### 4.3 桌面布局示意

```
┌──────────────┬──────────────────────────────┐
│  MusicX      │                              │
│  发现  我的  设置   │     (内容区)               │
│              │                              │
│   (无歌单直接   │      [ 迷你播放条 ]            │
│    堆在侧栏)   │                              │
└──────────────┴──────────────────────────────┘
```

## 5. 播放页布局(聚焦体验)

### 5.1 结构

```
┌──────────────────────────────┐
│  ▲ 收起        ▦ 歌词/唱片切换  │   ← 顶部:收起 + 轻量切换
│                              │
│        [ 大封面/黑胶旋转 ]     │   ← 主体:封面为视觉焦点
│                              │
│        歌名(大字)             │
│        歌手(灰字)             │
│                              │
│  ────────────●───────────    │   ← 进度条(品牌红细线)
│  01:23              04:56    │
│                              │
│  ⏮     ▶/⏸     ⏭    [队列]  │   ← 控制键集中底部
└──────────────────────────────┘
```

### 5.2 要点

- 大封面作主体(带缓慢旋转的"黑胶"效果),**不**用封面做全屏渐变背景(对齐主流,更耐看)。
- 唱片/歌词通过**顶部轻量切换**或点击封面切换,**不再挤底部**。
- 进度条、时间、控制键组成**一块干净控制区**;队列改为控制键右侧图标,点击弹出底部弹层。
- **移除播放页紫光晕渐变背景**,改用 `bg` + 封面自然色彩。
- 控制键中央播放/暂停为品牌红大圆,两侧上/下一首为灰色图标。

## 6. 组件与列表规范

### 6.1 歌曲行(SongTile)

- 封面 + 歌名 + 歌手 + 时长。
- 分隔线极淡(`divider`)。
- 当前播放行:`accent` 左侧小竖条 + 红色歌名高亮。

### 6.2 导航项(侧边栏/底栏)

- 当前项: `accentSoft` 圆角底 + 红色图标;其余灰色。

### 6.3 卡片(Card)

- 无边框、`surface` 底、大圆角(20)、无阴影或极浅阴影;靠间距区分。

### 6.4 输入框 / 搜索条

- `surfaceHi` 填充、无边框、圆角 16;聚焦时 `accent` 细边。

---

## 7. 主题切换机制(新增)

### 7.1 状态与持久化

- 新增 `ThemePreference`(`Notifier<ThemeMode>`),值为 `light` / `dark`,默认 `light`。
- **持久化**到本地文件(`~/.musicx/settings.json` 或其他现有配置路径),读写在启动时加载。
- 与现有 `SearchSourceNotifier` 模式保持一致(同文件 `settings_providers.dart`)。

### 7.2 应用方式

- `AppTheme` 提供 `light` 与 `dark` 两套 `ThemeData`(基于第 3 节的 Token)。
- 根 Widget 依据 `ThemePreference` 选择主题;不再是固定 `dark`。

### 7.3 设置入口

- 设置页(一级 tab)"外观"分区:浅色 / 深色 单选。

## 9. 验收标准

1. 应用默认浅色「月光极简」:黑白灰 + 品牌红点缀,无紫粉渐变残留。
2. 导航为三 tab:发现/我的/设置;无独立"播放"tab;播放页从歌曲/迷你条进入。
3. 设置页可切换浅色/深色,选择被持久化,重启后保持。
4. 播放页布局符合第 5 节:封面主体 + 顶部切换 + 底部干净控制区。
5. `flutter analyze` 无错误;全量测试通过;关键重构功能(导航/播放/主题切换)有测试覆盖。

---

## 10. 非目标(不在此次范围)

- 不改播放/搜索/下载等**核心数据逻辑**,仅重构 UI 呈现与结构。
- 不新增社交/评论等网易云特有的"云村"功能,保留"插件聚合搜索"产品定位。
- 不做跨端(Android/iOS/桌面)平台级差异适配,统一响应式布局。
